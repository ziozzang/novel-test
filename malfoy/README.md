# 말포이 양은 지는 법을 모른다

일곱 해를 이기기만 한 영애가 단 한 번 지는 이야기.

J. K. 롤링의 『해리 포터』 본편 7권을 바탕으로 한 비상업 2차 창작입니다. 드라코 말포이가 딸로 태어났다는 것 하나만 바꾸고, 그 딸의 1인칭으로 원작을 다시 씁니다. 원작의 사건과 결말은 그대로 둡니다.

- 1~4부(학창 시절)는 전 연령입니다.
- 5부(두 인물 모두 성인)는 성인 구간이며, 성애 장면은 간접 묘사로만 다룹니다.

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `malfoy.epub` | 삽화 수록판. 프롤로그, 5부 64장, 종장. 표지 1장과 장별 삽화 66장 |
| `SYNOPSIS.md` | 시놉시스. 방향, 인물, 장별 줄거리, 원작 사건 인용 색인 |

## 전자책 구성

- 표제지, 작품·독서 안내, 부별 목차, 제작 기록을 수록했습니다.
- 각 장은 장 제목 → 삽화 → 본문 순서입니다. 전자책 목차에서 각 부와 66개 장으로 이동할 수 있습니다.
- 본문 문장은 초판과 같습니다. 삽화는 전자책용 JPEG로 최적화했으며, 파일 크기는 약 15.2MB입니다.
- 최신 파일은 [GitHub Releases](https://github.com/ziozzang/novel-test/releases/latest)에서도 받을 수 있습니다.

AI 생성물 여부, 원문 인용, 권리에 관한 고지는 저장소 최상위 [README](../README.md)를 따릅니다.
