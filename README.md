# novel-test

> **이 저장소는 테스트용입니다.** 인공지능으로 장편 소설 창작이 어디까지 가능한지 시험해 보는 저장소이고, 여기 있는 파일은 그 실험의 결과물입니다. 정식 배포본이 아니며, 내용과 파일은 예고 없이 바뀌거나 지워질 수 있습니다.

작품마다 디렉터리 하나를 쓰며, 각 디렉터리의 `README.md`에 그 작품의 소개와 파일 목록이 있습니다.

## 고지

- **AI 생성물**: 본문과 시놉시스는 자체 개발한 창작 엔진이 인공지능을 사용해 생성했으며, 삽화는 AI 이미지 생성 도구로 제작했습니다.
- **원문 인용 없음**: 모든 문장은 AI가 새로 생성한 것입니다. 원작에서 문장 단위로 인용하거나 옮긴 부분은 없습니다. 2차 창작에서 원작으로부터 가져온 것은 사건의 흐름과 설정이며, 시놉시스에 적힌 원작의 권·장 표시는 어느 사건을 바탕으로 했는지 알려 주는 출처 표시입니다.
- **권리**: 2차 창작물의 경우 원작의 인물, 설정, 세계관에 대한 권리는 원저작권자에게 있습니다.
